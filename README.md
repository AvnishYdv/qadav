# Qadav Language

Qadav is a next‑generation, **AGI‑native** programming language designed from the ground up for quantum‑inspired computation, post‑quantum cryptography, and built‑in machine‑learning primitives.  It is being built with the **Antigravity IDE** and **Gemini Code Agent** to ensure a fresh, modern toolchain without any legacy baggage.

The project aims to deliver:
- A clean Go‑based compiler front‑end that ultimately targets LLVM.
- Quantum‑inspired runtime layers and post‑quantum cryptographic algorithms.
- First‑class ML support integrated into the standard library.
- Full self‑hosting capabilities, eventually removing the need for Go/Rust/C/C++ bootstraps.

All development happens locally on Windows (and cross‑platform), with a focus on reproducible builds, strict typing, and security‑first design.
